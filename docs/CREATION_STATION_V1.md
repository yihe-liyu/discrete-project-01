# 创作台设计文档 V1（Creation Station）

> 状态：**设计定稿**（与作者 2026 年逐条拍板）。实现开始后本文是唯一真源，改动需回写本文。
> 关联：`docs/ARCHITECTURE.md`（五层模型 / 动词 / 所有权）。创作台落在"内容层 + 运行时"的缝上，是**创作者的预览沙盒**，不是编辑器。

---

## 0. 一句话

**一个真实运行时的内容创作台：目录里换壳选魂，代码里改数即看。**
跑的就是游戏本体（StageManager / BulletManager / 协程 / 幽灵玩家），不是模拟器——所见即最终效果。

## 1. 核心哲学（三条铁律）

1. **跑真代码**：所有预览 = 真实运行时。一致性 100%，无"复刻模型漂移"。
2. **壳魂分离**：外形/属性（壳）与 逻辑脚本（魂）独立选择；壳 = 试验道具（不落盘），魂 = 真实内容脚本。
3. **索引派生**：目录永不手写，按目录/命名约定 +`## @role` 注解从文件自动生成——不重蹈 enemy_presets 重复清单的覆辙。

## 2. 单位类型（可选择的演示单元）

| 单位 | 壳侧 | 魂侧 | 实现期 |
|---|---|---|---|
| `stage` 整关 | StageData | stage 脚本 | M4（合并现有整关预览） |
| `phase` 阶段 | Boss 视觉 + PhaseData 字段 | move_script × shoot_script（双槽） | M4 |
| `enemy` 敌人 | EnemyShell（外观/HP/判定/掉落） | enemy 行为脚本 | M3 |
| `bullet` 子弹 | BulletShell（贴图≡判定/染色/混合/初速/方向） | bullet 行为脚本 | M2 |
| `emitter` 发射台 | 无（锚点位置，可拖放） | 任意 boss_shoot 脚本（target=锚点）+ 可选幽灵 Boss 开关 | M2 |

嵌套天然成立：组合台跑真实系统，敌人脚本里的 `shoot_spread` 会正常生成携带自身行为脚本的子弹——无需预先展平。

## 3. 脚本角色分类

### 3.1 角色总表（6 种）

| 角色 | 约定判定（优先级 1） | 沙盒提供 |
|---|---|---|
| `stage` | `data/stages/**/stage_script/*.gd` | 整关环境 |
| `enemy` | `data/stages/**/enemy/*.gd` | 幽灵敌人实体 + 幽灵玩家 |
| `boss_move` | `*_move.gd` | 幽灵 Boss + 场地 |
| `boss_shoot` | `*_shoot.gd`（或阶段 .tres 的 shoot_script 字段） | 宿主（幽灵 Boss **或**发射锚点）+ 幽灵玩家 |
| `bullet` | `*_bullet.gd` 或 `data/stages/**/bullet/*.gd` | 单颗子弹 + 发射点 + 幽灵玩家（+可选幽灵 Boss） |
| `bg` 背景演出 | `data/stages/**/background/*.gd` | 幽灵舞台环境（M4 以后） |
| `player` | `scripts/coroutine/player/`（仅目录展示，不进组合台） | —— |

### 3.2 判定规则

1. 路径/命名约定（0 成本自动）
2. `## @role: xxx` 注解覆盖（最高优先级；`## @name:` 可覆盖默认显示名=注释首行）
3. 引用交叉校验：扫 .tres 的 move/shoot_script 字段 + 源码 preload 引用 → 生成"被谁引用"列；约定与注解打架 → warning 响亮提示

### 3.3 边界（防误收）

- 只扫 `res://data/`（内容边界）；`scripts/` 是引擎不进目录；`test/`、`addons/` 排除
- 只收 `extends CoroutineScript`（或 CoroutineRunner）的 .gd；`data/dialogue/` 及非演出资源出局

## 4. 界面结构：单窗口双页签

- **页签 A「整关预览」**：现有工作台原样（书签 / 12x / 逐帧 / 事件日志）
- **页签 B「单元组合台」**：左目录（关卡/阶段/敌人/子弹/发射台/协程脚本，可搜索、按角色筛选、缩略图卡片）｜中舞台（真实演出）｜右状态（时间/弹数/敌人/Boss/FPS/演示状态）
- 底部播放栏共享：难度 / 种子（固定开关 + 掷新种子）/ 幽灵玩家走位模式 / 静音 / 播放控制
- 当前选择（壳/魂/难度/种子/走位模式）**自动保存**，下次打开恢复

## 5. 壳面板细则

> **贴图 ≡ 判定**：选贴图即同时拿到贴图 + 判定形状/尺寸/偏移（来自 AssetRegistry.bullet_configs），面板只显示只读判定标签，不再有独立"判定"输入项。

### 5.1 子弹壳（M2）

- 常用：贴图（≡判定）· 染色 · 混合模式（乘法/加色）· 初速 · 发射方向（8 方位+自由角）
- 高级：加速度 · 出界宽限 · 可被 Bomb 消除（默认勾）· 命中音效 · 伤害
- 只读行：`参数由脚本 var 控制（热重载调参）`——面板不做参数编辑（与"调参走代码"决策一致）

### 5.2 敌人壳（M3）

- 常用：外观（13 种缩略图）· HP · 判定半径 · 掉落四类（P/点/残机碎片/雷碎片）
- 高级：击破分数 · 死亡特效 · 掉落散布
- 只读行：同子弹

### 5.3 阶段壳（M4）

- 魂侧双槽：move_script × shoot_script（各自可换/清空，默认取 .tres 现值）
- 常用：Boss 外观 · 阶段名 · 类型（非符/符卡 uid）· HP · 时限
- 高级：奖励分 · 掉落系列 · 开局减伤 · 背景替换

## 6. 演示循环

- **有限脚本**（返回 false / 击破 / 飞完出场）：播完 → 等待 X 秒（默认 2.0，可调）→ 自动重播（同种子）
- **无限脚本**（auto_stop=false）：到达演示时长（子弹默认 10s / 敌人 15s / 阶段=时限或击破）→ 等待 → 重播
- **无限发射提示**：黄/蓝标签「∞ 无限发射脚本」，**说明性提示，非错误红条**；tooltip 注明"演示由时长控制，到点自动重播"
- 自动循环开关；R 立即重播；重播间隔可调
- 防死循环：单位演示设最大弹数上限（默认 300），超限提示并停止生成（防止手滑的 `while true` 炸掉组合台）

## 7. 幽灵玩家走位（三模式，随时切换）

1. **鼠标跟随**（默认）：鼠标放哪，自机狙瞄哪——自机狙弹幕调感神器；暂停/逐帧时以最后位置为准
2. **自动漂移**：现有 ghost_player 行为
3. **静止**：固定中心

## 8. 热更新管线

- 触发：文件 mtime 轮询 0.5s（只盯当前单元相关路径）→ 检测变化 → 防抖 0.8s
- 重载：`ResourceLoader.load(path, "", CACHE_MODE_REPLACE)`，**连坐重载本单元全部脚本**（A 脚本 preload B 时编译结果持有旧 B，只 reload B 无效）
- 重建：整单元从 t=0 用当前种子重演
- 解析失败：保留旧版本继续演 + 顶部红条「重载失败：<错误>」
- 工作台开关（默认开），防止大项目误触发

## 9. 错误与契约（一律响亮，不静默）

| 情形 | 表现 |
|---|---|
| 脚本前置缺失（如用 p_ctx.boss 但没开幽灵 Boss） | 红条 + 原因 + 建议（勾选幽灵 Boss） |
| 重载解析失败 | 红条含错误行；旧版本继续 |
| 角色分类：约定与 `@role` 打架 | warning 列表页 |
| 参数键名 vs 脚本 var 名 | 启动时对表校验，不一致 push_warning |

**内容新规（写入 CONTENT_GUIDE）**：弹幕发射脚本只用 `target.global_position` 作发射位；确需 Boss 上下文 → 组合台勾选幽灵 Boss。

## 13. 风险与对策

| 风险 | 对策 |
|---|---|
| preload 依赖缓存（连坐问题） | 单元全量 CACHE_MODE_REPLACE 重载（单元仅 2~5 文件，代价可忽略） |
| 脚本上下文耦合过深 | 沙盒默认物 + 响亮报错 + 内容新规 |
| 手滑死循环炸掉组合台 | 单位弹数上限 (300) + 时刻上限 |
| 目录扫描性能 | 只扫 data/ + extends 文本预筛 + 缓存 |
